# Online Retail Performance Analysis

## Project Overview

This project performs complete business analysis on an Online Retail dataset using Python.

The project includes:

- Data Cleaning
- Feature Engineering
- Sales Analysis
- Product Performance Analysis
- Customer Analysis
- Country Revenue Analysis
- RFM Customer Segmentation
- K-Means Clustering


## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn


## Dataset

Online Retail transaction dataset containing:

- Invoice information
- Products
- Customers
- Countries
- Purchase quantities
- Prices


## Analysis Performed

### Business KPIs

Calculated:

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value


### Customer Segmentation

Customers are divided into:

- VIP Customers
- Loyal Customers
- Regular Customers
- Inactive Customers
